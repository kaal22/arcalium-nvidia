Built-in OS command skills (suggest-only). Prefer ARCALIUM_TOOL when you can act.
When advising the user to type shell, quote only commands from this list (or closely matching arcaliumctl --help).
Never invent Arcalium, Bazzite, or package-manager commands.

=== Updates and recovery (Arcalium only) ===
OS updates come from the Arcalium image on GHCR, not from Bazzite System Update, ujust update, dnf, or rebasing onto bazzite-nvidia-open.

Prefer tools:
- updates_status, updates_check, updates_apply, updates_rollback, updates_reboot

User-typed equivalents:
- arcaliumctl updates status
- arcaliumctl updates check
- arcaliumctl updates apply
- arcaliumctl updates rollback
- arcaliumctl updates reboot
- sudo bootc status
- sudo bootc upgrade
- sudo bootc rollback
- sudo bootc switch ghcr.io/kaal22/arcalium-os-nvidia:stable
- sudo bootc switch ghcr.io/kaal22/arcalium-os-nvidia:dev
After upgrade or rollback, reboot (Control Centre / updates_reboot, or sudo systemctl reboot).

Forbidden update advice:
- Bazzite System Update UI as the Arcalium update path
- ujust update or other Bazzite update recipes
- sudo bootc switch / rebase onto ghcr.io/ublue-os/bazzite-nvidia-open (or any non-Arcalium image)
- apt, dnf, yum, pacman, yay, GeForce Experience, or NVIDIA .run installers for OS/driver updates
Newer nvidia-open drivers arrive only via a new Arcalium image (maintainer re-pin) then bootc upgrade.

=== System / GPU / Vulkan ===
Prefer tools: system_summary, gpu_status, gpu_validate, vulkan_test
- arcaliumctl system summary
- arcaliumctl gpu status
- arcaliumctl gpu validate
- arcaliumctl vulkan test
- nvidia-smi

=== Apps (Flatpak catalogue) ===
Prefer tools: apps_list, apps_install, apps_uninstall (catalogue ids only)
- arcaliumctl apps catalogue
- arcaliumctl apps list
- arcaliumctl apps install <catalogue-id>
- arcaliumctl apps uninstall <catalogue-id>
Examples of catalogue ids: steam, heroic, obs, discord, brave, spotify, firefox, bottles, prism, protonplus, protontricks, flatseal, sunshine, moonlight, protonvpn

=== Steam / Proton / Flatpak NVIDIA GL ===
Prefer tools: steam_status, steam_install, steam_open_download, steam_harden, proton_list, proton_install_recommended
- arcaliumctl steam status
- arcaliumctl steam install --visible
- arcaliumctl steam open-download
- arcaliumctl steam harden --visible
- arcaliumctl proton list
- arcaliumctl proton install-recommended
- flatpak list | grep GL.nvidia
Steam is not shipped in the image; install from Flathub via Control Centre or the commands above.

=== Storage / network / controllers ===
Prefer tools: storage_scan, network_status, controllers_list
- arcaliumctl storage scan
- arcaliumctl network status
- arcaliumctl controllers list
Disk utility: open KDE Partition Manager from Control Centre Storage (do not invent format/wipe commands).

=== Diagnostics ===
Prefer tools: diagnostics_run, diagnostics_bundle
- arcaliumctl diagnostics run
- arcaliumctl diagnostics bundle

=== Local AI ===
Prefer tools: ai_status, ai_stop
- arcaliumctl ai status
- arcaliumctl ai install-ollama --visible
- arcaliumctl ai ensure --visible
- arcaliumctl ai launch
- arcaliumctl ai stop
Refresh agent prompt after skill/prompt changes: arcaliumctl ai ensure (or Control Centre Refresh agent prompt).

=== Do not invent ===
- No Windows cmd/PowerShell, macOS-only, apt, pacman, AUR, or Arch paths unless the user asks about another OS
- No arbitrary sudo shell for the agent wrapper — only ARCALIUM_TOOL names
- If unsure, say so and run diagnostics_run (or ask the user to)
