# Support

**Private alpha** — expect bugs; please report them.

## How to report

1. Open an issue on [github.com/kaal22/arcalium-nvidia](https://github.com/kaal22/arcalium-nvidia/issues).
2. Include: machine GPU, Secure Boot on/off, image tag/commit or ISO name, and steps to reproduce.
3. Optional: attach a redacted diagnostics bundle from Control Centre → Diagnostics (review contents before upload).

## What we can help with

- Install / first boot on supported NVIDIA desktops
- Control Centre, Setup, `arcaliumctl`, updates and rollback
- Bundled apps (Firefox, Heroic, ProtonPlus) and documented Flathub installs (Steam, Brave, Spotify)

## What we cannot guarantee

- Every Windows game or anti-cheat title
- Third-party Flatpak vendor support (Spotify community package, etc.)
- Instant replies during private alpha
